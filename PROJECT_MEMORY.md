# Hukum — Proje Hafızası

## Proje özeti
Godot 4.7.2, altı medeniyetli sıra tabanlı hex strateji oyunu; PARDEX entegrasyonu.

## Önceki bağlam / dikkat noktaları
Kullanıcı tercihleri: paneller altın çerçeve ve siyah iç dolgu, taşma olmamalı; butonlar dışa bombeli ve ölçeklenince bozulmamalı; avatarlar çerçeve dışına taşmamalı; medeniyet temaları tutarlı; sağ üst 'menü', ayarlar menünün içinde. Bunlar tarihsel taleplerdir; güncel kod ile doğrula.
